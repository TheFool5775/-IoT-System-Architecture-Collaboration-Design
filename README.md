TOPIC 1: TEXT PREPROCESSING

1. Introduction

Text preprocessing is an important step in Natural Language Processing (NLP). It involves preparing raw textual data into a suitable format for further analysis.

This practical exercise demonstrates three text preprocessing techniques using Python and the Natural Language Toolkit (NLTK).

2. Objectives

The objectives of this practical exercise are:

- To perform tokenization on social media text.
- To apply lemmatization to obtain meaningful base forms of words.
- To apply stemming to reduce words to their root forms.
- To compare the results obtained from the three techniques.

3. Tools and Technologies

- Programming language: Python
- NLP library: NLTK
- Data manipulation: Pandas
- Development environment: Google Colab / Jupyter Notebook

4. Methodology

A. Tokenization

Tokenization involves splitting text into smaller units called tokens, such as words, punctuation marks and symbols.

B. Lemmatization

Lemmatization converts words into their meaningful dictionary base forms while considering grammatical context.

C. Stemming

Stemming reduces words to their root forms by removing prefixes or suffixes. The resulting stems may not always be dictionary words.

5. Dataset

A sample dataset of social media-style posts was created for demonstration. It contains different word forms, punctuation and informal expressions.

6. Results and Discussion

The three techniques produced different transformations:

- Tokenization separated the posts into individual tokens.
- Lemmatization produced meaningful base words.
- Stemming reduced words using word-reduction rules.

The results demonstrate how text preprocessing prepares unstructured text for subsequent NLP tasks.

7. Conclusion

The practical exercise successfully demonstrates tokenization, lemmatization and stemming using Python and NLTK. These techniques are useful in preparing social media text for applications such as sentiment analysis, text classification and topic detection.

5. Examine the displayed preprocessing results.
